# 추경연 포트폴리오

백엔드·AI 서비스 개발 직무 지원을 위한 정적 포트폴리오입니다. 프로젝트에서 해결한 문제, 담당 범위, 설계 선택과 검증 한계를 설명합니다.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 에 접속합니다. Node.js 설치나 빌드 과정은 필요하지 않습니다.

## 구조

- `index.html`: 소개, 학력·활동, 분야별 기술 역량, 웹 작업물, AI 자동화, 프로젝트 요약, 연락처
- `projects/<project>/index.html`: 프로젝트별 문제·구조·검증·한계
- `assets/`: 공개용 화면 캡처 (자작 샘플·예시 데이터)
- `assets/web-work/`: 웹 작업물 캡처. 업체 의뢰 작업은 업체 이름·로고·연락처·주소·원본 사진·도메인을 뺀 익명 시안만 둡니다.
- `style.css`: 공통 디자인 토큰, 반응형 레이아웃, 인쇄 스타일
- `script.js`: 모바일 메뉴와 이메일 복사

## 환경변수

이 사이트에는 환경변수가 필요하지 않습니다. API 키·계정 파일·개인 문서는 업로드하지 않습니다. 연결 프로젝트의 `.env.example`은 실제 비밀 값이 없는 실행용 템플릿만 공개합니다.

## 기술 수준 기준

- 사용 경험: 결과물을 만들고 검증 기록을 남긴 기술
- 프로젝트 적용: 구현했지만 실제 실행 또는 통합 검증이 남은 기술
- 학습 중: 프로젝트에 적용하기 전인 기술

기술은 개발 언어, 백엔드·데이터베이스, AI·검색, 프론트엔드·모바일, 테스트·평가, 배포·개발 도구, 시스템·임베디드로 구분합니다.

## 배포

GitHub Pages의 `main` 브랜치 루트에서 배포합니다. 공개 파일만 명시적으로 선택해 커밋하고, 배포 workflow 성공 후 실제 사이트를 확인합니다. 이 폴더 밖의 지원 계획서·검토 보고서·원본 개발 문서는 배포 대상이 아닙니다.

## 수정할 때 확인

- 프로젝트 설명의 수치는 공개 소스·평가 결과·실행 기록과 일치해야 합니다.
- 기존 개발 기록과 이번 실행 결과를 구분하고, 자동 테스트·시뮬레이터·실기기·운영 배포를 같은 의미로 쓰지 않습니다.
- 신규 캡처에 실제 예약번호·개인 연락처·인증정보가 들어 있지 않은지 확인합니다.
- 이름·학력·졸업 예정·병역·자격증 날짜는 제출 전 본인이 확인합니다.
- 인쇄 또는 PDF 저장 시 브라우저 인쇄 미리보기에서 페이지 나눔을 확인합니다.
