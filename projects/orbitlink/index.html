OrbitLink

FreeRTOS 기반 우주선 통신 시스템을 다루는 운영체제 팀 과제에 참여했습니다. Queue & Priority와 Message Queue 구간을 담당했고, 우선순위 큐 구현과 메시지 전달의 재시도·백오프 통합을 진행했습니다.

담당한 문제

메시지를 우선순위에 따라 대기시키고, 전달에 실패한 경우 다시 시도하는 흐름을 다뤘습니다. 운영체제의 큐 개념을 메시지 전달 처리와 연결하는 역할을 맡았습니다.

담당 구간의 흐름

역할과 공개 범위

  • Queue & Priority, Message Queue 개발 구간을 담당했습니다.
  • 팀 프로젝트 전체를 개인 구현 성과로 표시하지 않았습니다.
  • 현재 공개 자료만으로 팀 전체의 최종 실행 결과를 확인할 수 없어 처리량·지연·성공률 수치는 제시하지 않았습니다.
